El primer paso de cualquier tarea de pronóstico es graficar los datos. Un gráfico temporal muestra las observaciones frente al tiempo y hace visibles la tendencia y la estacionalidad.

library(ggplot2)

# Convertir la serie mensual en un data frame para graficar
passengers <- data.frame(
  month = seq(as.Date("1949-01-01"), by = "month", length.out = length(AirPassengers)),
  count = as.numeric(AirPassengers)
)

ggplot(passengers, aes(x = month, y = count)) +
  geom_line(colour = "steelblue") +
  labs(
    title = "Pasajeros aéreos",
    x = "Mes",
    y = "Pasajeros (miles)"
  )

Figura 2.1 shows a clear upward trend. The seasonal pattern also grows with the level of the series: the summer peaks become larger every year.

2.1 Seasonal plots

A seasonal plot draws each year as a separate line, so that the shape of the seasonal pattern is easier to compare from one year to the next.

# One line per year, coloured from earliest to latest
passengers$year <- format(passengers$month, "%Y")
passengers$month_of_year <- as.integer(format(passengers$month, "%m"))

ggplot(passengers, aes(x = month_of_year, y = count, group = year, colour = year)) +
  geom_line() +
  scale_x_continuous(breaks = 1:12, labels = month.abb) +
  labs(x = "Month of the year", y = "Passengers (thousands)", colour = "Year")

July and August are the busiest months in every year of the data.
