Certaines méthodes de prévision sont extrêmement simples et pourtant étonnamment efficaces. Elles servent surtout de méthodes de référence : toute nouvelle méthode doit faire mieux qu’elles avant de valoir la peine d’être utilisée.

3.1 Méthode naïve et méthode naïve saisonnière

La méthode naïve utilise la dernière observation comme prévision pour toutes les périodes futures. La méthode naïve saisonnière utilise plutôt la valeur de la même saison de l’année précédente : la prévision pour juillet prochain est la valeur de juillet dernier.

h <- 24  # horizon de prévision en mois
last_year <- tail(as.numeric(AirPassengers), 12)

# Répéter la dernière année de données pour couvrir l’horizon
forecast_values <- rep(last_year, length.out = h)
future <- seq(as.Date("1961-01-01"), by = "month", length.out = h)

message(sprintf("%d prévisions produites à partir de %d observations", h, length(AirPassengers)))
24 prévisions produites à partir de 144 observations
plot(future, forecast_values, type = "l",
     main = "Prévisions naïves saisonnières",
     xlab = "Mois", ylab = "Passagers (milliers)")

Comme la série présente une forte tendance, les prévisions naïves saisonnières de la Figure 3.1 sont probablement trop basses. Une méthode qui modélise aussi la tendance ferait mieux.

3.2 Mesurer l’incertitude

A single number hides how uncertain a forecast is. A prediction interval gives a range in which the future value is expected to lie with a stated probability, such as 80% or 95%. Intervals usually become wider as the forecast horizon increases, because uncertainty accumulates over time.
